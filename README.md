# בנק הזמנות (Yazamut)

אפליקציית Google Apps Script (Web App) לשיעורי מצוינות מדעית-טכנולוגית.
תלמידות מביאות הזמנות אמיתיות של אנשים מהסביבה שלהן, תלמידות אחרות מאמצות ובונות תוצר, והתוצרים מוצגים בגלריה עם לבבות, משובים ופרופילים.

## מה יש בפנים
- **הלוח:** הזמנות, סינון, חיפוש, אימוץ, ופס התקדמות בן 8 שלבים.
- **הזמנה חדשה:** טופס עם אזהרת פרטיות ושאלון גודל (קנבס או אפפסקריפט).
- **גלריה:** תוצרים עם צילום מסך, הטמעה, לבבות, צפיות, משוב ופרופיל לכל תלמידה.
- **הצגה בכיתה:** המורה בוחרת מי מציגה, ולכולן נפתח התוצר עם טופס משוב. כולל תור הצגות, טיימר, דף הכנה לפיץ' וסיכום משובים.
- **ניהול (מורה):** חלון אימוץ לכל קבוצה (ז' / ח'), השוואה בין קבוצות, רשימת תלמידות, עריכה ויצוא.
- פיצול לפי קבוצות: כל תלמידה רואה רק את הקבוצה שלה. הרשמה עצמית בכניסה הראשונה.

## קבצים
| קובץ | תפקיד |
|---|---|
| `Code.gs` | שרת: הזמנות, אימוץ, משתמשות, הגדרות |
| `Gallery.gs` | שרת: גלריה, לבבות, משובים, פרופילים, הצגה בכיתה, סקירת מורה |
| `Index.html`, `Styles.html`, `Script.html` | ממשק (RTL, vanilla JS, ללא ספריות מלבד Google Fonts) |
| `appsscript.json` | הגדרות Web App (Execute as: Me, Access: Domain) |
| `Config.sample.gs.txt` | תבנית להגדרות מקומיות |

## התקנה
1. צרו פרויקט Apps Script וגיליון Google ריק. צרו תיקייה ב-Drive לצילומי המסך.
2. העתיקו את `Config.sample.gs.txt` לקובץ בשם `Config.gs` בפרויקט ומלאו את מזהה הגיליון ומזהה התיקייה. הקובץ הזה לא נכנס ל-git.
3. העלו את שאר הקבצים (ידנית, או עם `clasp`: העתיקו `.clasp.sample.json` ל-`.clasp.json` והכניסו Script ID, ואז `clasp push`).
4. בעורך הריצו את `setup()` פעם אחת ואשרו הרשאות (Sheets ו-Drive). הוא יוצר את הלשוניות ואת המורה הראשונה.
5. אופציונלי: `seedDemoData()` מוסיף 6 הזמנות לדוגמה.
6. Deploy → New deployment → Web app. Execute as: **Me**, Who has access: **Anyone within domain**.
7. כל שינוי בקוד דורש גרסה חדשה (Manage deployments → Edit → New version).

## גיליונות
`Orders`, `Users`, `Config`, `Projects`, `Hearts`, `Comments`, `Views`. לא לשנות את שורת הכותרות.
מורה = `role` בשם `teacher` בגיליון `Users`. תלמידות נרשמות לבד.

## אבטחה ופרטיות
- הרשאות נאכפות בשרת, לא רק בלקוח. כל כתיבה תחת `LockService`.
- הלקוח לא משתמש ב-`innerHTML` עם קלט משתמש. הטקסטים עוברים ולידציה ומגבלת אורך. טלפונים ומיילים נחסמים בטקסט חופשי.
- מיילים של תלמידות לא נשלחים ללקוח (רק למורה). פרופילים מזוהים במזהה מגובב.
- "הצעות לשיפור" גלויות רק ליוצרת התוצר, לכותבת ולמורה.
- הטמעת תוצרים נעשית ב-`iframe` עם `sandbox`, וקישורים חייבים להתחיל ב-`https://`.
